# Wareed BI Dashboards Hub (تجربة)

نسخة ثابتة (snapshot) من 3 لوحات BI الحالية، منسوخة كما هي بدون أي تعديل على منطقها أو بياناتها، فقط لتجربة استضافتها على GitHub Pages بتسجيل دخول بسيط.

## المحتوى
- `index.html` — صفحة تسجيل الدخول + قائمة اللوحات.
- `dashboards/executive.html` — نسخة من لوحة التنفيذي (Executive Dashboard).
- `dashboards/reservations.html` — نسخة من لوحة الحجوزات (Reservations Dashboard).
- `dashboards/wareed-bi-live.html` — نسخة من حزمة Wareed BI Live (نفس لوحة تطبيق الأندرويد).

كل ملف داخل `dashboards/` أضيف له سطر واحد أعلى الملف (guard script) يتحقق من تسجيل الدخول قبل عرض الصفحة مباشرة.

## بيانات الدخول (تجريبي)
- **المستخدم:** `Admin`
- **كلمة المرور:** `Admin123`

## تنويه مهم — هذا ليس حماية أمنية حقيقية
تسجيل الدخول هنا يتم بالكامل داخل المتصفح (JavaScript) وكلمة المرور مكتوبة بشكل صريح داخل كود `index.html`. أي شخص يفتح "عرض مصدر الصفحة" (View Source) أو أدوات المطوّر يقدر يشوف كلمة المرور أو يتجاوز الفحص تمامًا. هذا الأسلوب مناسب فقط لمنع الدخول العرضي أثناء التجربة، وليس لحماية بيانات حساسة فعليًا.

كذلك: حتى لو كان المستودع (Repo) على GitHub **خاص (Private)**، فإن رابط GitHub Pages الناتج يكون **متاحًا للجميع** بمجرد معرفة الرابط (على الحسابات المجانية) — الخصوصية على مستوى المستودع لا تعني خصوصية على مستوى الموقع المنشور. الحماية الحقيقية لاحقًا تحتاج استضافة بخادم فعلي مع تسجيل دخول من طرف الخادم (server-side).

## هذه نسخة ثابتة وليست مباشرة (Live)
البيانات المعروضة هي لقطة من وقت الرفع فقط، ولا تتحدث تلقائيًا. التحديث الدوري (عبر GitHub Actions مثلاً) خطوة لاحقة إذا احتجناها بعد التجربة.
